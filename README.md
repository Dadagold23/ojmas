## About OJMAS_Journal

OJMAS_Journal is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. OJMAS_Journal takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://OJMAS_Journal.com/docs/routing).
- [Powerful dependency injection container](https://OJMAS_Journal.com/docs/container).
- Multiple back-ends for [session](https://OJMAS_Journal.com/docs/session) and [cache](https://OJMAS_Journal.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://OJMAS_Journal.com/docs/eloquent).
- Database agnostic [schema migrations](https://OJMAS_Journal.com/docs/migrations).
- [Robust background job processing](https://OJMAS_Journal.com/docs/queues).
- [Real-time event broadcasting](https://OJMAS_Journal.com/docs/broadcasting).

OJMAS_Journal is accessible, powerful, and provides tools required for large, robust applications.

## Learning OJMAS_Journal

OJMAS_Journal has the most extensive and thorough [documentation](https://OJMAS_Journal.com/docs) and video tutorial library of all modern web application frameworks, making it a breeze to get started with the framework. You can also check out [OJMAS_Journal Learn](https://OJMAS_Journal.com/learn), where you will be guided through building a modern OJMAS_Journal application.

If you don't feel like reading, [Laracasts](https://laracasts.com) can help. Laracasts contains thousands of video tutorials on a range of topics including OJMAS_Journal, modern PHP, unit testing, and JavaScript. Boost your skills by digging into our comprehensive video library.
